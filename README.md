# Exercice 1 — Système de dessin de formes
Ce résultat montre le calcul et l’affichage des caractéristiques des différentes formes géométriques. Il illustre le polymorphisme grâce à l’utilisation d’une même méthode pour plusieurs types de formes.

# Exercice 2 — Gestion d’une bibliothèque multimédia

# Exercice 3 — Personne, Développeur et Manager
Ce résultat affiche les salaires calculés pour les développeurs et le manager selon leurs taux de majoration respectifs. Il illustre l’héritage, la classe abstraite et le polymorphisme à travers la redéfinition de la méthode `calculerSalaire()`.
